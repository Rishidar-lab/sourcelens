# Vector store
chromadb==0.5.23
# chromadb>=0.5 declares `posthog>=2.4.0` with no upper bound. Newer posthog
# majors (this pin included) changed the signature of the free-function
# `posthog.capture(distinct_id, event, properties)` that chromadb's telemetry
# client calls positionally, which raised a TypeError on every vector-store
# operation ("capture() takes 1 positional argument but 3 were given"),
# caught internally by chromadb and logged as noise on every request. The
# actual fix is in code: app/repositories/chroma_store.py registers a no-op
# telemetry client via Chroma's own `chroma_product_telemetry_impl` setting,
# so no posthog version fixes or breaks this - it's pinned here only so a
# fresh install doesn't pull in the correct-but-larger v3+ analytics stack
# than this local single-user app has any use for.
posthog==7.42.0
